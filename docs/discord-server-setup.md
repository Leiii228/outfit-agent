# Discord Server 設定步驟

> 這份文件教你在**自己已經有的 Discord Server** 裡：
> 1. 新建一個給穿搭 agent 用的頻道
> 2. 拿到這個頻道的 CHANNEL_ID
> 3. 產生邀請連結，讓同學加入（測試「分人處理」要用）
>
> 以下以 **Windows 版 Discord 桌面程式、介面語言為繁體中文** 為準。括號裡是英文介面的名稱，你的 Discord 如果是英文就看括號。
> bot 本身的建立和邀請，請看另一份 `docs/discord-bot-setup.md`。

---

## 一、新建 #穿搭紀錄 頻道

1. 打開 Discord 桌面程式。
2. 在**畫面最左邊那一排圓形圖示**裡，點你自己的 Server。
3. 在左邊第二欄的頻道列表裡，找到「**文字頻道**」（TEXT CHANNELS）這個分類標題。
4. 滑鼠移到「文字頻道」這幾個字上，右邊會出現一個 **＋** 號，點它。
   - 如果找不到：改成在左上角的 **Server 名稱**上按右鍵 → 選「**建立頻道**」（Create Channel）。
5. 跳出「建立頻道」視窗後：
   1. 「頻道類型」選 **文字**（Text），也就是前面有 **#** 的那個。
   2. 在「頻道名稱」框框裡輸入 `穿搭紀錄`。
   3. 下面的「**私人頻道**」（Private Channel）開關**保持關閉**。
      - 關閉時，Server 裡的每個人都看得到這個頻道，同學加入後就能直接傳照片，測試最方便。
      - 如果你想只讓特定的人使用（`docs/architecture.md` 第 17 節提到的額度考量），可以打開，但之後要記得把同學和 bot 都加進這個頻道。初次測試建議先關著。
6. 點右下角的「**建立頻道**」（Create Channel）。
7. 左邊頻道列表會出現 **# 穿搭紀錄**，這一步完成。

---

## 二、拿到這個頻道的 CHANNEL_ID

CHANNEL_ID 是 Discord 給這個頻道的固定編號，一串 17～19 位的數字。agent 只會聽這個編號的頻道。要看到這個編號，必須先打開「開發者模式」。

### 步驟 1：打開開發者模式（只要做一次）

1. 在 Discord **畫面左下角**，你的頭像和名字的右邊，有一個**齒輪圖示**（使用者設定，User Settings），點它。
2. 左邊會出現一長串設定選單，往下捲到「**應用程式設定**」（App Settings）這一區。
3. 點「**進階**」（Advanced）。
4. 右邊第一個項目是「**開發者模式**」（Developer Mode），把它右邊的開關**打開**，變成綠色。
5. 按鍵盤左上角的 **Esc** 鍵，或點右上角的 **X**，離開設定。

### 步驟 2：複製頻道 ID

1. 回到你的 Server，在左邊頻道列表的「**# 穿搭紀錄**」上按**滑鼠右鍵**。
   - ⚠️ 是在**頻道名稱**上按右鍵，不是在左上角的 Server 名稱上。在 Server 名稱上複製到的是「伺服器 ID」，填進去 agent 會找不到頻道。
2. 選單最下面會有「**複製頻道 ID**」（Copy Channel ID），點它。
   - 如果沒看到這一項，表示開發者模式還沒打開，回去做步驟 1。
3. 這時編號已經複製起來了。打開「記事本」，按 **Ctrl + V** 貼上，就可以看到一串數字，例如 `1301234567890123456`。

### 步驟 3：記下來

這串數字之後要填進 `.env` 檔的 `CHANNEL_ID=` 後面（怎麼建立 `.env` 寫在 `docs/discord-bot-setup.md` 的第五節）。

> CHANNEL_ID **不是密碼**，被別人看到也沒關係，可以貼給 Claude Code。真正要保密的是 bot token。

## 三、產生邀請連結讓同學加入

測試「分人處理」至少需要**兩個不同的 Discord 帳號**在同一個頻道傳照片，所以要請同學加入你的 Server。

1. 在左邊頻道列表的「**# 穿搭紀錄**」上按**滑鼠右鍵**。
2. 選「**邀請其他人**」（Invite People）。
   - 也可以把滑鼠移到頻道名稱上，點右邊出現的「**人形＋**」小圖示。
3. 跳出邀請視窗，下面有一行連結，例如 `https://discord.gg/xxxxxxx`。
4. 建議先調整連結的有效期限，不要讓連結永久有效：
   1. 點連結下方的小字「**編輯邀請連結**」（Edit invite link）。
   2. 「**失效時間**」（Expire After）：選 **1 天** 或 **7 天**。
   3. 「**最大使用次數**」（Max Number of Uses）：選大約是同學人數的數字，例如 **5 次**。
   4. 點「**產生新連結**」（Generate a New Link）。
5. 回到邀請視窗，點連結右邊的「**複製**」（Copy）。
6. 把這個連結用 LINE 或其他方式傳給同學，同學點開後按「**接受邀請**」（Accept Invite），就會加入你的 Server。
7. 同學加入後，左邊頻道列表會看到 **# 穿搭紀錄**，請他在裡面傳照片測試。

> 提醒：
> - 同學在這個頻道傳的每一張照片，都會用掉**你自己的** Claude 額度。只邀請你信任、確定要幫忙測試的人。
> - 不要把邀請連結公開貼在網路上。

---

## 完成檢查

- [ ] 左邊頻道列表有 **# 穿搭紀錄**
- [ ] 記事本裡有一串 CHANNEL_ID 數字
- [ ] 至少一位同學已經加入你的 Server，看得到 # 穿搭紀錄

接下來請照 `docs/discord-bot-setup.md` 建立 bot，並把它邀進這個 Server。
